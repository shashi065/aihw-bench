# Examples

The `examples` directory contains runnable configuration and extension examples that match the implemented framework.

## Available Examples

| Directory | Purpose |
| --- | --- |
| `examples/configs` | Reference benchmark configuration for CLI and CI smoke tests. |
| `examples/plugins` | Minimal plugin package using the `aihw_bench.plugins` entry point. |
| `examples/reports` | Notes for generated report artifacts. |

Use these examples as small, deterministic starting points before connecting host-specific model runtimes or accelerator plugins.
