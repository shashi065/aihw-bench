# AI Hardware Benchmark Suite

AI Hardware Benchmark Suite is a production-oriented Python framework for benchmarking AI workloads across software runtimes, general-purpose processors, GPUs, embedded systems, simulator-backed environments, and future accelerator plugins.

The repository currently includes the foundation, core infrastructure, benchmark engine, model support, hardware backend layer, metrics engine, reporting engine, visualization layer, CLI, plugin framework, testing and QA system, professional documentation site, release engineering system, and v1.0 production-readiness audit.

The project is governed by the [AIHW-Bench Project Constitution](constitution.md).

## Implementation Principle

The project is implemented subsystem by subsystem. A subsystem is complete only when it has production code, public documentation, tests, CLI or API integration where relevant, and CI coverage.
